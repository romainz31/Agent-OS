## `life_forget` — oubli volontaire

Utilise cet outil seulement après une demande explicite d'oubli/suppression.
Passe `record_ids` si les identifiants sont connus, sinon `query`. Si plusieurs
éléments correspondent, demande lequel supprimer. L'oubli est logique et
audité : aucune autre donnée personnelle n'est effacée par proximité.
