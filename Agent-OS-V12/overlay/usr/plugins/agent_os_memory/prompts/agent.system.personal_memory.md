## Contrat mémoire personnelle V12

Tout message utilisateur peut contenir plusieurs informations utiles. Le
pipeline local sépare les captures, les requêtes, les corrections, les oublis
et les demandes de précision.

Le texte source est conservé sans perte. Les dates relatives sont résolues
avec la date locale, les tâches portent un état sémantique, les actions
conservent leurs occurrences, et les personnes ou lieux peuvent recevoir des
attributs versionnés.

Qwen local propose une structure JSON, mais Python la valide. SQLite est la
source de vérité et aucune réponse de Paul ne doit devenir une mémoire
utilisateur. Une question sans preuve locale reçoit une réponse d'absence
plutôt qu'une invention. Une information incomplète reste en clarification
jusqu'à ce que l'utilisateur fournisse le détail manquant.
